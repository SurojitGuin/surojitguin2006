Ch.1 — Reference vs. sampled signal

continuous reference physical samples (rate = fs)

The reference curve is evaluated on a fixed 600-point plotting grid used only for drawing a smooth line — it is not the sampling process. The amber stems are the actual instants the ADC would take at the chosen fs; only these are used below for reconstruction and spectra.

Ch.2 — Sinc-reconstructed waveform

reference reconstructed (Σ y[n]·sinc(fs(t−n/fs)))

Reconstruction sums sinc kernels over samples taken from a slightly wider guard window than shown, so edge truncation doesn't masquerade as reconstruction error inside the displayed 60 ms.

Ch.3 — Magnitude spectrum

|X(f)| of the sampled sequence f₁, f₂ (true) fs/2 (this case's Nyquist limit)

Frequency axis is fixed 0–260 Hz in every case so the three regimes are directly comparable. Spectrum content only exists up to fs/2 — where that cutoff falls, and what shows up below it, is the whole story.

Mandatory validation — manual alias frequency

Independent hand calculation using f_alias = |f − round(f/fs)·fs|, cross-checked against the peak actually measured in Ch.3.

Physical sampling rate (fs, sets the amber sample instants and everything derived from them) is kept separate in the code from plotting resolution (the fixed 600-point / 1 s grids used only to draw smooth curves and estimate the spectrum) — changing plotting resolution redraws the same physics, changing fs changes it.
